🎮 Terminal Games in Python

A small collection of classic terminal games written in pure Python, built as one of my first programming projects. 
The games are played in Swedish and run in any terminal, no installation needed.

The games

1. Hängagubbe (Hangman)

Guess the secret word one letter at a time. You have 20 wrong guesses before you lose. The game keeps track of which letters you got right and wrong.

2. Gissa numret (Guess the number)

A secret number between 1 and 100 is generated at random. After each guess you get a hint whether it was too high or too low, and the game counts how many guesses you needed.


Features

*Menu-driven interface: pick a game, return to the menu, or exit
*Input validation: rejects non-numbers and out-of-range guesses
*Guess counter in every round
*Correct and incorrect letters tracked in Hangman
